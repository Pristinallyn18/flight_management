# Flight Management System (CM500292)

A Python and SQLite command-line app for managing flights, destinations and pilot assignments for Azure Global Airways.

## How to run
python main.py

## Files
- main.py: the application
- flights.db: the database
- schema.sql: creates the tables
- sample_data.sql: sample data (AI-generated, as permitted by the brief)
- queries.sql: the tested SQL queries
